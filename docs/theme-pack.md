# 主题包制作指南（T-06 UGC）

> 给"想给小鹏换张脸 / 分享自己做的宠物"的人看。**不需要会写代码**，会用画图和压缩包就行。

## 一、主题包是什么

一个主题包 = 一个 ZIP 压缩包，扩展名改成 `.xptheme`：

    theme.json          清单（必须，放在压缩包根目录）
    pet.png             主形象（清单里 image 指向它）
    frames/nod/01.png   动作帧（可选）
    frames/wave/01.png
    preview.png         预览图（可选）
    说明.md             说明（可选）

它能带的东西：**宠物形象、动作帧、气泡样式、界面皮肤（明暗 + 强调色）**。

它**不能**带的东西：任何代码。只允许图片（png/gif/webp/jpg/jpeg/bmp/apng）与文本（json/md/txt），
出现 .exe/.py/.js/.dll 之类会被导入端直接拒绝并提示文件名。这是刻意的：主题只描述"长什么样"，
代码的载体是插件，两者的信任级别完全不同。

## 二、三步做一个

### 1. 先在应用里把形象调满意

设置 → 桌面宠物 → 宠物图片 / 动作帧。看着顺眼了再打包——主题包是"把已经调好的效果封起来"，
不用一开始就按包结构整理文件。

### 2. 一键打包

设置 → 桌面宠物 → **制作主题包…** → 填名称/作者/授权协议 → 生成。
保存下来的 `.xptheme` 就是成品，直接能发给别人导入。

想要更细的控制（自己放帧、自己写清单），点 **下载制作模板**，里面有一份
`theme.json` 样例 + 默认形象 + 制作说明，按同名替换文件即可。

### 3. 分享

主题包卡片上点 **分享文案**，会复制一段带名称、作者、体积、SHA256 和安装说明的 Markdown，
直接贴到群里 / 小红书 / B 站动态即可。对方收到 `.xptheme` 文件后：
设置 → 桌面宠物 → 主题包 → **导入主题包**。

## 三、theme.json 字段说明

```json
{
  "format": "xiaopeng-theme",
  "formatVersion": 1,
  "id": "com.yourname.orange-cat",
  "name": "橘猫",
  "version": "1.0.0",
  "author": "你的昵称",
  "description": "一句话介绍",
  "license": "CC-BY-4.0",
  "homepage": "",
  "tags": ["猫", "可爱"],
  "image": "pet.png",
  "actions": { "nod": ["frames/nod/01.png"], "wave": [], "blink": [], "jump": [] },
  "scale": 1,
  "bubble": { "bg": "#ffffff", "color": "#222222", "fontSize": 12, "radius": 8 },
  "skin": { "theme": "dark", "accent": "#5b8cff" }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `format` | ✅ | 固定 `xiaopeng-theme`，写错会被提示"这不是小鹏工具箱主题包" |
| `formatVersion` | ✅ | 当前为 `1`；比客户端新会被拒绝（提示升级应用），不会勉强解析 |
| `id` | ✅ | 小写反向域名式，**全网唯一**，如 `com.yourname.orange-cat`（导入时按它判断是覆盖还是新增） |
| `name` | ✅ | 显示名，≤ 40 字 |
| `version` | | 默认 `1.0.0`，形如 `1.0.0` / `1.2` |
| `author` / `description` / `license` / `homepage` | | 展示与授权信息，homepage 只接受 http/https |
| `tags` | | 最多 8 个，每个 ≤ 16 字 |
| `image` | ✅ | 主形象，必须是包内真实存在的图片 |
| `actions` | | 动作帧；动作名只认 `nod` / `wave` / `blink` / `jump`，每个动作最多 60 帧 |
| `scale` | | 显示缩放 0.25~4，默认 1 |
| `bubble` | | 气泡样式；`bg`/`color` 只接受 `#rgb`/`#rrggbb`/`#rrggbbaa`，`fontSize` 9~24，`radius` 0~24 |
| `skin` | | 界面皮肤。**默认不会自动套用**，用户勾选"同时套用界面皮肤"才生效 |

> 引用的文件必须真实存在于包里。少一个文件导入就会失败，并明确告诉你是哪个文件——
> 这是为了不让"清单说有、包里没有"变成宠物窗一片空白的静默故障。

## 四、常见问题

**导入报"已安装同 id 主题包"？**
说明你之前装过同 id 的包，确认后覆盖更新即可。

**别人导入后看不到效果？**
检查主题包里是不是多套了一层目录。要求 `theme.json` 就在压缩包**根目录**，
即"全选文件再压缩"，而不是"压缩整个文件夹"。

**导出的包多大算正常？**
纯 PNG 形象一般几十 KB 到几百 KB。GIF 动作帧会大一些。单文件上限 8MB、总计 64MB、
最多 512 个文件——超了会在导入端被拒绝。

**授权怎么写？**
请只使用你有权分享的素材，并在 `license` 写明协议（推荐 CC-BY-4.0）。
留空视为"保留所有权利"，别人就不能二次分发。

## 五、实现说明（给想改代码的人）

- 纯函数层：`shared/themePack/zip.ts`（ZIP 读写 + 路径安全）、`shared/themePack/inflate.ts`
  （RFC 1951 解压，零依赖）、`shared/themePack/manifest.ts`（清单校验规则）；
- 主进程服务：`electron/services/themePack.ts`（导入/导出/制作/应用/分享）；
- 导入是**先审后解**：先读中央目录拿到"声明的解压后大小"，校验路径、条目数、压缩比、
  文件类型之后才开始解压，且解压到暂存目录、全程成功才原子替换。
  外挂 tar/Expand-Archive 做不到这一点（中央目录与本地头可以不一致，是 zip-slip 的经典绕过面）。
- 主题包不含任何可执行能力，这是与插件的根本边界。
