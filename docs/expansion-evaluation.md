# 小鹏工具箱 — 竞品对标与拓展评估

> 目标：以「DustDesk / DeskNest（桌面收纳）」为候选方向，补充 3+ 个同类/互补开源项目，逐项对标
> 小鹏工具箱当前能力，得出需要拓展的功能与改进优先级。
> 评估时间：本报告由当前会话产出，所有链接可点击跳转 GitHub。

---

## 一、当前小鹏工具箱已有能力（基线）

| 维度 | 现状 | 备注 |
|------|------|------|
| 框架 | Electron + Vue3 + TS，Python 插件子进程 | 生态熟、开发快，但内存/体积偏重 |
| 桌面宠物 | 无边框透明窗口、帧动画、单击/双击/拖动、上传自定义 | 差异化亮点 |
| 侧边栏 | 右侧毛玻璃、拖拽调宽、置顶区/普通区、编辑排序 | 已有较成熟卡片体系 |
| 快捷启动 | 扫描已装应用 + 手动选 exe，拼音/首字母搜索 | 基础版 |
| 文件管理 | 最近/收藏/全盘搜索/隐私排除 | 有雏形 |
| 服务器启动 / 网站启动 | 命令、.bat/.py/.exe、远程；网址 | 已具备 |
| 待办 / 系统信息 / 音乐 | 宠物提醒、systeminformation、SMTC | 已具备 |
| 插件系统 | Python 3.10+ JSON-RPC over stdio，模块/宠物两类；**插件市场 v1（HTTPS 索引 + SHA256 + 权限提示）已落地**，命令可进全局命令面板 | 已具备 |
| 丰富插件 | 截图/录屏/转换/翻译/OCR + **AI 用量管家**，共 15 个（13 功能 + 2 示例），引擎随包内嵌 | 优势 |
| 桌面工作台 | DeskBox 式主面板（左功能列 + 中央搜索/应用网格 + 右侧功能卡），**非常驻：呼之即来、用完即走** | 差异化亮点 |
| AI 能力 | DeepSeek 对话/人设/记忆、语音输入与 TTS 播报、Agent 工具（待办/音乐/找文件/截图）、MCP 对外工具协议、**AI 造插件向导** | 独有组合 |

**结论（2026-09 更新）：小鹏工具箱是「桌面宠物 + 多模块侧边栏 + 桌面收纳 + 全局命令面板 + Python 插件平台 + AI 造插件」的组合体。**
早期评估中缺的 **桌面收纳可视化层、全局命令面板、剪贴板历史、插件市场、AI 增强** 已全部落地（见下方落地进展）；下一阶段的差距在 **国际化（i18n）、UGC 主题/皮肤包市场、文档站**。

## 二、推荐对标项目清单（含 DustDesk 共 8 个）

### A. 桌面收纳 / 桌面整理（与 DustDesk 同赛道）

1. **DustDesk / DeskNest**（候选 4 号）
   - 仓库：[LAIJiangFeng/tauri-dustdesk](https://github.com/LAIJiangFeng/tauri-dustdesk)
   - 技术栈：Tauri 2 + Rust
   - 核心：桌面按分类收纳、桌面↔收纳箱拖拽、一键批量启动、剪贴板历史、全局搜索。
   - 优点：功能聚焦、深入细致；Rust 性能好、资源占用低。
   - 可借鉴：**桌面上直接放"收纳区"，实时拖拽**这个交互形态。

2. **DeskBox**
   - 仓库：[Tianyu199509/DeskBox](https://github.com/Tianyu199509/DeskBox)
   - 技术栈：WinUI 3（原生感 Widget）
   - 核心：原生质感桌面整理，C#，WinUI 3 组件。
   - 可借鉴：**"原生质感/真实感"**、Widget 化呈现、与 Windows 外观无缝融合。

3. **desktop_box**
   - 仓库：[kof2000git/desktop_box](https://github.com/kof2000git/desktop_box)
   - 技术栈：.NET 8 + WPF，单文件 71MB，无遥测，开源 Fences 替代品
   - 核心：一键整理"把文件分进带标签的盒子，但**并不真正移动文件**"；拖拽盒子、原生 shell 右键菜单、隐藏桌面图标。
   - 可借鉴：**"归类但不移动源文件"**（安全、可逆，避免真实文件移动带来的风险）——这是很重要的一条产品原则。

4. **bentodesk**
   - 仓库：[ZRainbow1275/bentodesk](https://github.com/ZRainbow1275/bentodesk)
   - 技术栈：Rust
   - 核心：Bento 风格（格子卡片）桌面收纳，安静优雅。
   - 可借鉴：**Bento/格子式卡片视觉**，与现有侧边栏卡片风格呼应。

### B. 全局启动器 / 命令面板（效率入口的升级方向）

5. **Flow Launcher**
   - 仓库：[Flow-Launcher/Flow.Launcher](https://github.com/Flow-Launcher/Flow.Launcher)
   - 核心：热键召唤的启动器，Everything 极速文件搜索、应用/网页/命令，**插件生态庞大**。
   - 可借鉴：**Everything 集成做秒级全文搜索**、**命令面板（Command Palette）入口**。

6. **ZTools（uTools 开源实现）**
   - 仓库：[ZToolsCenter/ZTools](https://github.com/ZToolsCenter/ZTools)
   - 核心：高性能、可扩展的**应用启动器 + 插件平台**，跨 macOS/Windows。
   - 可借鉴：**"插件平台/市场"模型**——把现成的 Python 插件系统升级为"插件商店 + 一键安装 + 自动更新 + 分类"。

### C. 剪贴板 / 高能小工具（补齐另一大短板）

7. **Workbench-APP**
   - 仓库：[tk-wxy/Workbench-APP](https://github.com/tk-wxy/Workbench-APP)
   - 技术栈：Tauri 2.0 + Rust
   - 核心：热键唤出的**全屏效率面板**，一块面板集成"应用启动 + 剪贴板历史 + 文件中转"；用完即消失。
   - 可借鉴：**"单面板三合一"**的极简交互，与现有侧边栏结合，做成"全局呼出面板"。

8. **Memodock / inspector-rust**（剪贴板细分）
   - 仓库：[NikCraftsApps/MemoDock](https://github.com/NikCraftsApps/MemoDock)、[pepperonas/inspector-rust](https://github.com/pepperonas/inspector-rust)
   - 核心：隐私优先剪贴板历史（文本+图片、置顶、时间线、托盘、自动刷新，SQLite，离线）；inspector-rust 是键盘优先的剪贴板超级工具箱（片段、文本展开、屏幕 OCR、截图、取色、ML 抠图）。
   - 可借鉴：**剪贴板历史 + 片段库/文本展开**、**剪贴板图片 OCR**、**取色器**。

### D. 桌面宠物（现有亮点如何升级）

9. **Desktop-pet（Live2D + AI）**
   - 仓库：[git2968/Desktop-pet](https://github.com/git2968/Desktop-pet)
   - 核心：Live2D 模型、AI 对话、人设配置、语音输入、**MCP 工具扩展**。
   - 可借鉴：**给宠物接入 AI 对话/语音**、**人设配置**、**MCP 工具扩展**（让宠物能调用工具）。

## 三、对标结论：小鹏工具箱需要拓展/改进的功能（按优先级）

### P0 — 高价值、立即可做（与 DustDesk 方向强相关）

1. **桌面收纳可视化层（核心新增）**
   - 桌面放"收纳盒/收纳区"，支持拖拽文件进/出盒子、分类。
   - **关键原则：归类/分盒但默认不移动真实文件**（借鉴 desktop_box），或提供"仅整理视图 / 真移动"开关。
   - 支持标签、折叠、隐藏桌面图标、按扩展名/时间自动分类规则、跨显示器。
   - 与现有侧边栏卡片视觉统一（卡片/Bento 风格）。

2. **全局命令面板（启动器升级）**
   - 全局热键呼出一个"命令面板"，统一搜索：应用、文件、网址、服务器命令、待办、剪贴板、插件命令。
   - 引入 Everything 做秒级全盘文件搜索（小鹏当前全盘搜索是 fs 递归，慢）。
   - 支持拼音/首字母/大小写模糊匹配（现有快捷启动已有基础，扩展到全局）。

3. **剪贴板历史 + 片段库**
   - 历史（文本+图片），置顶、时间线、托盘常驻、自动刷新、离线存储（升级到 SQLite 更稳）。
   - 片段/文本展开、剪贴板图片 OCR、取色器。
   - 隐私：排除关键词/白名单、一键清空、可选加密。

### P1 — 增强体验、值得投入

4. **插件平台化 / 插件市场**
   - 现有 Python 插件系统已跑通协议；升级为"插件商店"：分类、一键安装、自动更新、依赖管理、评分/信任等级。
   - 考虑是否兼容 JS/TS 插件（降低受众门槛）。

5. **AI 增强宠物**
   - 宠物接入 AI 对话/语音（借鉴 Desktop-pet）；人设配置。
   - 让宠物/工具栏调 AI 能力（翻译、OCR、摘要、写作），与现有转换/翻译插件打通。

6. **系统整合与工程优化**
   - 多显示器适配、托盘常驻、开机自启、全局快捷键管理页。
   - 数据从 JSON 迁移到 SQLite（剪贴板、历史、搜索索引更稳）。
   - 隐私面板：排除文件夹、白名单、加密。

### P2 — 战略性抉择（需谨慎评估）

7. **框架迁移：Electron → Tauri 2 + Rust**
   - 你的候选 DustDesk、以及 Workbench、bentodesk、inspector-rust 都选 Tauri+Rust，核心卖点就是**资源占用少**。
   - 小鹏是 Electron + Python 子进程插件，内存和包体积偏大。
   - 若用户明确重视"轻量"，需评估：迁移收益 vs 工作量（宠物帧动画、透明窗口、Python 插件子进程在 Tauri 下的兼容）。
   - **建议**：先以模块化方式做增量（新功能用轻量路径），把 Tauri 迁移作为一个独立的、有明确 ROI 的专项再决策，不要一上来就推翻现有栈。

## 四、落地建议（下一步）

1. 先选定"桌面收纳 + 全局面板"作为本轮扩展主线（与你的 DustDesk 候选一致）。
2. 采用**"归类不移动真实文件"**的产品原则，降低用户顾虑。
3. 数据层升级到 SQLite，为剪贴板/搜索/历史打底。
4. 把现有 Python 插件系统朝"插件市场"演进，形成差异化护城河。
5. 每一项参考清单中标注了来源，可依次 clone 阅读源码细节。
