# AI 宠物生成 Prompt（给小白）

想让 AI 帮你创建**专属于你的桌面宠物**？复制下面"复制区"发给任意 AI，它会给你一个 Python 脚本；
在电脑上运行脚本即可生成宠物图片与动作帧，然后在「小鹏工具箱 → 设置 → 桌面宠物」里一键应用。

## 操作步骤

1. 复制"复制区"发给 AI（把方括号里的描述改成你的喜好）；
2. 把 AI 给的代码保存为 `make_pet.py`，放在任意文件夹；
3. 安装依赖（一次性）：
   ```powershell
   python -m pip install Pillow
   python make_pet.py
   ```
4. 脚本会在当前目录生成：
   ```
   pet/                 ← 将此文件夹作为 宠物帧文件夹
   ├── idle/1.png idle/2.png ...
   ├── nod/1.png ...
   ├── wave/1.png ...
   ├── blink/1.png ...
   ├── jump/1.png ...
   └── 宠物.png         ← 默认待机图
   ```
5. 打开 小鹏工具箱 → 设置 → 桌面宠物 →「选择图片」选 `宠物.png`；
6. 分别点击点头/摆手/眨眼/跳动 →「选择帧」→ 多选对应动作帧 → 立即生效。

## 复制区（从这里开始复制）

```
你是一位图形学编程助手。请帮我用 Python 生成一套“桌面宠物”动作帧图片。

【规格（严格遵守）】
- 全部图片为 128x128 像素、RGBA 透明背景的 PNG；
- 主体居中，占画面约 70%；画面简洁可爱；
- 生成 5 个动作，每个动作 3~6 帧（帧之间是连续动画的微小变化）：
  - idle  站立待机（轻微呼吸起伏）2~3 帧
  - nod   点头致意 3~4 帧
  - wave  抬起手/耳朵左右摆动打招呼 4~6 帧
  - blink 眨眼（睁眼→闭眼→睁眼）3 帧
  - jump  向上跳起落下 4~6 帧
- 使用 Pillow 库绘制（ImageDraw），不要依赖外部图片素材；
- 输出目录结构：
  pet/
    idle/1.png ... 
    nod/1.png ...
    wave/1.png ...
    blink/1.png ...
    jump/1.png ...
    pet.png（等于 idle 第 1 帧，作为默认待机图）
- 中文注释只写关键步骤，代码可直接运行生成全部文件；
- 运行完成后打印最终文件列表和总数。

【我的宠物形象】
（这里填写：例如——一只圆滚滚的蓝色小鲸鱼，有白色肚皮和小翅膀；
 或者：一只戴眼镜的橘猫；或者：一只戴粉色围巾的白色北极熊）

【输出要求】
只输出一个完整的 Python 脚本（命名为 make_pet.py）+ 运行方法 3 行，不要其它解释。
```

## 复制区（到这里结束）

## 提示

- 觉得不好看？把 AI 生成的脚本再原样发给 AI 一次，让它"调整配色/造型/动作幅度"即可迭代；
- 也可以让 AI 直接用「像素风」（参考本仓库 `scripts/generate-assets.mjs` 的画法）；
- 帧文件也可以来自 AI 生成的 GIF/APNG：设置中「选择图片」直接支持 GIF/APNG 动图单文件宠物。

## 相关能力（v2.1 追加）

- **人设不止外貌**：设置 → 桌面宠物 还可配置 名字 / 性格 / 口癖 / **世界观·自我介绍**，四者都会注入对话提示词（T-05）。
- **宠物会说话**：开启「语音播报」后，宠物气泡消息（聊天回复、待办提醒、AI 用量播报）会用系统语音朗读，语速可调并可试听。
- **形象路径健壮性**：宠物形象路径会做规范化与存在性校验（脏值如字面量 `""`、文件被删都会自动回退内置默认形象），图片加载失败时显示 🐾 占位——**宠物窗永远不会变成"看不见却挡住点击"的空白窗**。
- 动作帧同样会过滤失效文件：自定义帧缺失时自动回退内置帧目录（`resources/pet-frames/<动作>`）。
