## 1. 背景与目标

小鹏工具箱已是功能面完整的组合体（桌宠+侧边栏+收纳盒+命令面板+插件平台+AI），但对照 uTools/Quicker/PixPin/Listary/PowerToys（见调研报告），**高频刚需入口**仍有明显缺口：上下文动作面板、开发者小工具集、划词多动作、格式化粘贴、指令别名。

**目标**：以最小改动复用既有基础设施（命令面板、工作台、translateBar、ClipboardApp），把这四类缺口补齐到主流水准，让开发者/极客用户日常 80% 的效率动作在工具箱内闭环。

## 2. 目标用户与用户故事

目标用户：开发者/极客（接受复杂配置，重视可扩展性与响应速度）。

| 编号 | 用户故事 |
|------|----------|
| US-1 | 作为开发者，我在命令面板输入 `json {…}` 就能立刻看到格式化结果并一键复制，不用打开浏览器搜"json 格式化" |
| US-2 | 作为开发者，我选中一段报错文本按热键呼出工作台，能看到"翻译/搜索/复制/大小写"等针对这段文本的动作，一步执行 |
| US-3 | 作为用户，我在资源管理器选中文件呼出工作台，能一键"打开所在目录/复制路径/预览/归档到收纳盒" |
| US-4 | 作为用户，我给常用插件命令设短别名（如 `fy` = 中英互译），输入别名直达 |
| US-5 | 作为用户，我复制了乱格式的 JSON/带样式的文本，能选择"格式化粘贴/纯文本粘贴" |
| US-6 | 作为极客，我希望能看到新版本提示并一键跳转 GitHub Release |

## 3. 功能需求

> 编号体系沿用规格说明书：CP=命令面板、CH=剪贴板、WK=工作台（新增）、DEV=开发者工具（新增）、AL=别名（新增）。

### 3.1 P0 — M1 工作台智能化（WK-01 ~ WK-06）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| WK-01 | 呼出工作台（Ctrl+Shift+D / 托盘）时自动抓取上下文：选中文本、选中文件路径、剪贴板内容、前台应用 | 抓取耗时 ≤ 300ms；抓取期间剪贴板监听暂停、结束后自动恢复原内容（复用 translateBar 机制） |
| WK-02 | 按上下文显示动作分组：文本→翻译/搜索/复制/大小写转换/去空格/朗读；文件→打开所在目录/复制路径/预览/归档收纳盒；URL→网页快开；剪贴板图片→贴图/OCR | 上下文类型识别正确（文本/路径/URL/图片 ≥ 95%）；每组动作 ≥ 4 个 |
| WK-03 | 常用动作可固定（Pin）到工作台常驻区；动作按使用频率排序（复用 `palette_usage`） | 固定后重启保留；高频动作显著前移 |
| WK-04 | 上下文抓取可关闭（设置 → 通用 → 工作台：`deskboardContextCapture`，默认开启） | 关闭后工作台行为与现状完全一致 |
| WK-05 | 无上下文时工作台显示现状（功能列+搜索+卡片），不回归 | 关闭抓取或抓取失败时 UI 与当前一致 |
| WK-06 | 「归档到收纳盒」动作**默认不启用**（用户手动启用/固定后才显示）；收纳盒功能关闭时强制隐藏 | 默认状态下不出现该动作；开关联动正确 |

### 3.2 P0 — M2 开发者工具百宝箱（DEV-01 ~ DEV-12）

> 全部**内置实现**（`shared/` 纯函数 + 命令面板即时结果），零第三方依赖。

| 编号 | 工具 | 验收标准 |
|------|------|----------|
| DEV-01 | JSON 格式化/压缩 | 输入即显；非法 JSON 给出错误位置；回车复制结果 |
| DEV-02 | 时间戳转换（秒/毫秒 ⇄ 本地时间/ISO） | 自动识别 10/13 位时间戳与日期字符串 |
| DEV-03 | Base64 编/解码、URL 编/解码 | 双向自动识别 |
| DEV-04 | 正则测试（表达式 + 测试文本，高亮匹配） | 独立小面板；常用正则预设 ≥ 5 条 |
| DEV-05 | 哈希（MD5/SHA1/SHA256） | 文本即时出三值 |
| DEV-06 | UUID v4 生成 | 一键生成并复制 |
| DEV-07 | 进制转换（2/8/10/16） | 同屏四进制对照 |
| DEV-08 | 单位/进制换算（长度/数据大小/时间） | ≥ 3 类单位族 |
| DEV-09 | 二维码生成/解码 | 文本→二维码显示；粘贴图片→解码 |
| DEV-10 | cron 表达式解析（未来 5 次触发时间） | 中文自然语义提示 |
| DEV-11 | 文本 diff 对比 | 独立小面板，行级高亮 |
| DEV-12 | 命令面板即时结果化：DEV-01/02/03/05/06/07 输入即显（如 `ts 1727...`） | 首屏 ≤ 100ms；沿用计算器的即时结果置顶机制 |

### 3.3 P1 — M3 划词动作条 + 格式化粘贴（CH-07 ~ CH-10 / WK-07）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| WK-07 | 划词悬浮条升级为**可配置动作条**：翻译/搜索/复制/大小写/去空格/朗读/自定义命令 | 默认动作 ≥ 6 个；可在设置增删排序 |
| CH-07 | 粘贴面板/剪贴板历史支持**纯文本粘贴**（Ctrl+Shift+T 类，去格式） | 粘贴结果无字体/颜色等样式 |
| CH-08 | **JSON 格式化粘贴**：剪贴板为 JSON 时可格式化后粘贴 | 与 DEV-01 共用纯函数 |
| CH-09 | **图片 OCR 转文字粘贴**：剪贴板为图片时一键 OCR 后以文本粘贴 | 复用既有 `ocr.ts`；识别语言沿用 Tesseract 配置 |
| CH-10 | 上述动作入口同时出现在：粘贴面板右键、工作台上下文（图片组） | 入口一致可达 |

### 3.4 P1 — M4 别名与智能匹配（AL-01 ~ AL-03 / CP-07）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| AL-01 | 任意功能/插件命令/网站可设自定义别名（如 `fy`） | 别名输入直达；冲突检测提示 |
| AL-02 | 别名管理页（增删改查、批量导入导出） | 设置 → 系统集成 或 命令面板内管理 |
| AL-03 | 别名纳入搜索源，匹配权重最高 | 输入别名时目标结果第一 |
| CP-07 | **粘贴智能匹配**：检测到剪贴板为路径/URL/JSON/时间戳等，命令面板顶部推荐对应动作（路径→归档/预览，URL→快开，JSON→格式化） | 识别正确率 ≥ 95%；推荐动作可一键执行、可关闭 |

### 3.5 轻量项 — 检查更新（UPD-01）

| 编号 | 需求描述 | 验收标准 |
|------|----------|----------|
| UPD-01 | 启动后（可关）检查 GitHub Releases 最新版本，发现新版在托盘/设置提示并一键跳转下载页 | 检查失败静默；频率 ≤ 1 次/天；不自动下载安装 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 命令面板即时结果 ≤ 100ms；工作台呼出 ≤ 300ms；首屏 ≤ 200ms 既有标准不回退；空闲内存 ≤ 250MB 不回退 |
| 安全 | 上下文抓取仅内存态，不落盘、不上传；剪贴板恢复必须可靠（断电/崩溃不破坏原剪贴板——失败时至少不写入错误内容） |
| 兼容 | 不引入全局鼠标/键盘钩子；不新增第三方运行时依赖；既有插件协议（PM-03 commands）完全兼容 |
| 数据 | 别名、动作固定、使用频率入 SQLite `(key,value)` 既有表结构；`npm test` 增补断言 |
| 质量 | `shared/` 纯函数全部纳入 `npm test`；`npm run typecheck` / `lint` 零告警 |

## 6. 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 范围过大 | 高 | P0/P1 硬边界，P1 可整体顺延下一迭代 |
| 剪贴板抓取副作用 | 中 | 复用 translateBar 保护机制；WK-04 可关 |
| 内置工具复杂度 | 中 | 纯函数 + 测试断言 |
| GitHub Releases 访问不稳（大陆网络） | 低 | 检查失败静默，不影响主流程 |
