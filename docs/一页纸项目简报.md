# 一页纸项目简报 — 主流化功能补齐（T-14 系列）

> 版本：v1.0（已冻结 2026-09-27）
> 日期：2026-09-27
> 上游文档：`docs/调研报告-2026-09.md`、`tasks.md`（T-01~T-13 既有路线不受影响）

---

## 项目一句话简报

**把已有的「命令面板 + 工作台 + 剪贴板/划词」三条入口升级为主流软件水准的效率中枢：工作台智能化（上下文感知，承载"超级面板"能力）、开发者工具百宝箱内置进命令面板、划词动作条与格式化粘贴，让开发者/极客用户"一个工具箱顶替 uTools+Quicker+PixPin 的常用 80%"。**

## 目标用户与痛点（已确认）

- 目标用户：开发者/极客（接受复杂配置，重视可扩展性）。
- 核心痛点：主流效率工具的高频刚需在本工具箱缺位——上下文动作面板、开发者小工具集、划词多动作、格式化粘贴、指令别名。
- 对标决策：uTools/Quicker（全能效率）+ PixPin/Ditto（截图剪贴板）+ Listary/Flow Launcher（搜索启动）。

## MVP 范围（本轮做）

| 优先级 | 模块 | 内容 | 架构决策 |
|--------|------|------|----------|
| P0 | **M1 工作台智能化**（承载 A1 超级面板） | 呼出工作台时自动感知上下文（选中文本/文件/剪贴板/前台应用），按上下文显示动作分组：文本→翻译/搜索/复制/大小写/朗读；文件→打开所在目录/复制路径/预览/归档收纳盒；常用动作可固定 | **扩展现有工作台（deskboard），不新造面板**；上下文抓取复用划词翻译的"模拟 Ctrl+C + 剪贴板保护"方案，**不引入全局鼠标钩子** |
| P0 | **M2 开发者工具百宝箱**（A2） | 命令面板即时结果 + 独立小面板：JSON 格式化/压缩、正则测试、时间戳转换、Base64/URL 编解码、进制/单位换算、哈希（MD5/SHA）、UUID、二维码生成/解码、cron 解析 | **内置实现**（共享层纯函数，零依赖毫秒级），高频 7 项即时结果化 |
| P1 | **M3 划词动作条 + 格式化粘贴**（A3+A4） | 划词悬浮条从"翻译/OCR"扩展为可配置动作条（翻译/搜索/复制/大小写/去空格/朗读/自定义）；粘贴面板新增纯文本粘贴、JSON 格式化粘贴、图片 OCR 转文字粘贴 | 扩展既有 `translateBar` / `ClipboardApp` |
| P1 | **M4 别名与智能匹配**（A5+A9） | 指令/插件命令/功能支持自定义短别名；粘贴文本/文件路径后命令面板智能推荐对应动作（如路径→"归档到收纳盒"、URL→"网页快开"） | 扩展 `paletteSearch` |

## 非目标（本轮明确不做）

- ❌ 自动下载更新（A6 完整版）：分发源未定（开放问题 Q3），本轮只做**"检查更新 + 提示跳转"**轻量版。
- ❌ 全局鼠标钩子（长按右键/侧键触发）：与现有"无全局钩子"原则冲突，列入下轮评估（Q4）。
- ❌ 贴图类型扩展/标注补齐/录屏 GIF（B4~B6）、窗口管理小工具（B7）、网络小工具（B10）、Agent 工具总线（C1）：B/C 档下一轮。
- ❌ i18n、UGC 主题、商业化（原 T-12/T-13 路线不变）。
- 不删任何既有功能（沿 tasks.md 原则）。

## 成功指标（可量化）

| 指标 | 目标 |
|------|------|
| 命令面板开发者工具即时结果响应 | ≤ 100ms（输入即显） |
| 工作台呼出 → 显示上下文动作 | ≤ 300ms；目标动作 ≤ 2 步可达 |
| 划词动作条覆盖动作数 | ≥ 6 个（含自定义） |
| 开发者工具覆盖场景 | ≥ 10 类，每类有验收用例 |
| 既有指标不回退 | 面板首屏 ≤ 200ms；空闲内存 ≤ 250MB（T-10 既有标准） |
| 迁移成本 | uTools 用户上手无需看文档即可完成"JSON 格式化 + 划词搜索 + 上下文归档"三件事 |

## 主要风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| 范围过大导致半成品 | 高 | M1/M2 为 P0 硬边界，M3/M4 可顺延；每个模块独立验收 |
| 工作台上下文抓取干扰剪贴板 | 中 | 复用 translateBar 既有"取词期间暂停监听+自动恢复"机制 |
| 内置工具增加主仓复杂度 | 中 | 纯函数集中在 `shared/`，全部纳入 `npm test` 断言 |
| 自动更新分发源未定（Q3） | 中 | 轻量"检查更新"兜底，完整版待分发源确定后立项 |
